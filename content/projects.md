    <div class="project-tags">
      <span class="project-tag">Kotlin</span>

      <span class="project-tag">Mobile</span>

      <span class="project-tag">Git</span>

    </div>
    <p>A mobile app that displays live amusement park wait times using clean MVVM architecture. I built this to solve my personal problem of not being able to see Kings Island wait times while not at the park.</p>
    <p>I integrated REST APIs with Retrofit, built a reactive UI with StateFlow, and implemented dependency injection via Hilt to create maintainable, scalable code. The app demonstrates modern Android development practices with Jetpack Compose and a focus on user experience, allowing users to check wait times from anywhere. The clean architecture and separation of concerns make it easy to add support for additional parks and features in the future.</p>
